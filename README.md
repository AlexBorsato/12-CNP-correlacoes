# PNS do 12º CNP × INFRA-BR, IPS Brasil e ODS

Relatório que correlaciona as 55 Propostas Nacionais Sistematizadas (PNS) aprovadas no 12º Congresso Nacional de Profissionais (Confea, Vitória/ES, 2025) com os indicadores do INFRA-BR 2026, do IPS Brasil 2024 e com os Objetivos de Desenvolvimento Sustentável da Agenda 2030.

- `index.html`: relatório interativo (publicado via GitHub Pages)
- `Relatorio_PNS_12CNP_INFRABR_IPS_ODS.pdf`: versão expandida em PDF
- `PNS_12CNP_x_INFRABR_IPS_ODS.xlsx`: planilha com o mapeamento completo
